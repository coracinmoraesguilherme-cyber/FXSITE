# 📖 About

The **FXSMP Website** is the official portal for the **FXSMP: UNAXIS** project.

Its purpose is to provide players with a modern, responsive and immersive platform where they can access everything related to the project in one place.

Unlike a simple landing page, the website is designed to become the central hub of the community.

# 🎨 Design Goals

The visual identity follows four main principles:

- Minimalism
- Modern UI
- Smooth interactions
- Immersion

The goal is to make the website feel like an extension of the Minecraft world rather than just an information page.

# 🌌 About Unaxis

**FXSMP: UNAXIS** is a fantasy-oriented Minecraft project focused on exploration, progression, RPG mechanics, magic, technology and storytelling.

Players will discover forgotten civilizations, hidden structures, magical artifacts and ancient mysteries scattered across the world.

> *Time can destroy a civilization, but it cannot completely erase what it left behind.*

# 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/your-user/fxsmp-website.git
```

Enter the folder:

```bash
cd fxsmp-website
```

Open:

```
index.html
```

or use Live Server in VSCode.
